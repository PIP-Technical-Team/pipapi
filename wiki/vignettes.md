## Use Cases

### Use Case 1: Research and Analysis
Researchers can use pipapi to:
- Download poverty and inequality data programmatically
- Reproduce World Bank poverty estimates
- Conduct sensitivity analysis with different poverty lines
- Generate custom aggregations for publications

### Use Case 2: Dashboard and Reporting
Data visualization tools can use the REST API to:
- Fetch real-time poverty statistics
- Build interactive dashboards
- Generate automated reports
- Integrate PIP data into existing systems

### Use Case 3: Policy Simulation
Policy analysts can use pipapi to:
- Simulate the impact of poverty line changes
- Compare poverty estimates across different PPP vintages
- Model distributional impacts of policy interventions
- Validate country-level poverty assessments

*Use case documentation will grow with real-world adoption patterns.*
